# Scanner Terminal App

Operator-focused screens for barcode scanner terminals and tablets.

Main workflows:
- Material receiving scan
- Storage location scan
- Picking scan
- Issue to line
- Feeder and reel binding
- PCB station scan
- Repair scan
- Finished goods scan

Design rules:
- Large buttons
- Minimal typing
- Fast scan response
- Clear success/fail sound and color feedback
- Offline retry queue if network is unstable
