# Apps

User-facing applications.

```text
apps/
|-- web/                  Main browser app for office, warehouse, production, quality
|-- scanner-terminal/     Touch/scanner optimized app for warehouse and SMT operators
`-- display-board/        Large-screen dashboard for production floor and managers
```

Default ports:

```text
web: 5173
scanner-terminal: 5174
display-board: 5175
```
