# Web App

Browser-based operational console for office users, management, planners, warehouse supervisors, engineers, quality, and administrators.

Implemented first version:
- Factory dashboard with SMT line status and KPI cards
- PMC customer PO and work order view with 11-digit code demonstration
- WMS material lots, IQC status, storage, and issue actions
- SMT scanner workflow with reel, PCB, and work order recognition
- Feeder binding view
- Quality inspection, defect, and repair closure records
- Traceability timeline from customer PO through finished goods
- Reports and role permission matrix
- Chinese, Vietnamese, and English UI switching
