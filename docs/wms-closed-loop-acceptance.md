## 3D 同步规则

- 权威方向：工位/WMS → MES 数据中心 → 3D。
- 3D 只读取 `/api/3d/wms-snapshot`，无权审批、冻结、释放或修改库存。
- 每个浏览器读取同一 PostgreSQL 快照，不使用浏览器本地库存状态。
- 快速定位支持物料码、批次、原材料库位、SN、工单、箱码、栈板码、
  成品库位、闭环单号和交接单号。
- 3D 同步一致性专项测试已通过（两个独立客户端获得相同业务快照）。

## 四方整合规则

统一入口：`/api/integration/operations-snapshot`

| 节点 | 权威内容 | 可向下游发布 | 不允许 |
|---|---|---|---|
| MES | 工单、BOM、工序顺序、确认 NG、维修生命周期 | 工单与路由要求、确认 NG 广播 | 覆盖设备原始结果、直接改库存 |
| WMS | 批次、库存台账、库位、交接、成品库存 | 可用性、冻结、交接状态 | 改写工位测试结果 |
| Station | 设备结果、CSV/Excel/数据库结果、心跳、本地待传队列 | 现场事实和状态变化 | 在 MES 恢复后覆盖上游已确认历史 |
| PDA | 扫码观察、人员身份、实物收货确认 | 扫码事实与交接确认 | 将扫码直接当作生产 SN 记录 |
| 3D | 只读显示与报警 | 无 | 锁站、审批、修改任何业务数据 |

网络恢复后按事件编号、来源、版本、时间和哈希对账；冲突进入隔离队列，
不得静默覆盖。下游默认接受上游权威事实，互向数据必须按字段所有权裁决。
