# 非 SMT 材料闭环

## 四种管理模式

- `DIRECT_SN`：外壳、关键部件和线束，逐件扫码并绑定产品 SN。
- `DIRECT_LOT`：插件、螺丝和连接线，首次上料或换 Lot 扫码，按数量核销。
- `PACKAGING_UNIT`：标签、说明书、彩盒、外箱和托盘，每个包装单位扫码绑定。
- `INDIRECT_CONSUMABLE`：胶水、锡丝、助焊剂和清洁剂，按领用、称重、退回及报废核销。

## 标准闭环

物料分类 → BOM → 工单需求 → WMS领料 → 工位接收 → 扫码防错 → 使用/绑定 →
退料或报废 → 数量核对 → BOM核销 → 成本结算 → 工单关单。

## 强制规则

- 所有工位扫码都进行 BOM、工单、物料分类、历史绑定和质量状态检查。
- 扫描只提供操作证据，不直接创造库存。
- 相同事件编号重传不重复累计；相同编号不同内容产生 CRITICAL 冲突。
- 逐件绑定历史不可删除，维修更换使用 `REPLACED` 状态保留新旧关系。
- 退料必须由 WMS 扫码接收；理论数量与实盘不同进入差异调查。
- 数量容差只决定报警等级，关单时所有差异仍必须有原因。
- SMT 与非 SMT 数据、库存账户和业务流水隔离，通过 BOM、工单及统一审计关联。
