# Workflows

## Dashboard to Module Navigation

```text
Dashboard -> PMC / WMS / MES / Quality / Traceability / Reports / Admin
```

## PO to Work Order

```text
Customer PO -> Product/BOM check -> Work order code -> Schedule -> Release
```

## Receiving to SMT Line

```text
Receiving -> Label -> IQC -> Storage -> Pick -> Issue to line -> Feeder binding
```

## SMT Production

```text
Setup -> Material anti-error -> First article -> Batch production -> Inspection -> Output
```

## Quality Closure

```text
Defect -> Analysis -> Repair/Rework -> Reinspection -> Closure -> Trace record
```

## Finance Posting

```text
Shipment / Receiving -> Invoice reference -> GL posting -> Period close -> Audit trail
```
