# OA 虚拟员工受控文件管理规范

**文件编号**：OA-AI-GOV-001  
**发布部门**：OA / 工厂管理  
**状态**：受控文件  
**版本**：1.0

## 管理原则

OA 是全部虚拟员工行为规范、作业指导书、Excel 模板、表单和审批规则的唯一发布中心。业务模块可以起草文件，但只有 OA 已批准并发布的当前有效版本可以成为虚拟员工执行依据。

## 支持的文件

- Markdown、Word、PDF：政策、SOP、岗位职责、审批规则和异常处理。
- Excel、CSV：导入模板、参数表、阈值、供应商、物料和计算规则。
- 图片、流程图：岗位路径、现场动作和布局指导。
- JSON：机器可执行的规则、字段约束和路由配置。

## 每份文件必须记录

- 文件编号、标题、分类、归口部门和业务负责人。
- 版本、文件名、文件类型、校验值、存储位置和上传时间。
- 适用虚拟员工、强制/参考属性、优先级和适用范围。
- 起草人、审核人、批准人、发布时间、生效时间和失效时间。
- 替代版本、变更原因、审批意见和完整审计记录。

## 状态

```text
DRAFT → PENDING_APPROVAL → APPROVED → PUBLISHED → SUPERSEDED / VOIDED
```

- `DRAFT`：仅可编辑，不得执行。
- `PENDING_APPROVAL`：等待 OA 人工审批，不得执行。
- `APPROVED`：已批准但尚未发布，不得执行。
- `PUBLISHED`：当前有效，允许虚拟员工读取并执行。
- `SUPERSEDED/VOIDED`：仅供审计，不得执行。

## 虚拟员工执行规则

1. 开始任务前按员工编号、业务域和任务类型查询 OA 当前有效文件。
2. 强制文件缺失、过期或校验失败时停止执行并报警。
3. 任务记录必须写入使用的文件编号和版本。
4. 同一规则存在多个版本时只执行 OA 标记的当前发布版本。
5. Excel 中的参数必须先通过字段、单位、范围和重复值校验。
6. 文件变更不得追溯修改已完成任务；历史任务保留原版本引用。
7. Hermes 监督文件缺失、过期、冲突和员工未确认，不替代 OA 批准人。

## 审批与发布权限

- 起草：归口部门负责人或被授权虚拟员工。
- 业务审核：对应业务负责人。
- 合规/财务审核：规则涉及质量、金额或法定要求时必须加入。
- 最终批准与发布：OA 授权管理员。
- 虚拟员工无权批准或发布自己的规则。
