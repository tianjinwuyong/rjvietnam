# 最低库存补购与 OA 审批作业指引

**文件编号**：OA-PROC-WMS-001  
**发布部门**：OA / 越南工厂管理  
**适用范围**：WMS 库存安全、采购、PMC、财务、工厂负责人及供应商协同  
**规则版本**：1.0  
**状态**：OA 受控文件

本文件受《OA 虚拟员工受控文件管理规范》（OA-AI-GOV-001）管理。只有 OA 状态为 `PUBLISHED` 的当前版本可供虚拟员工执行。

## 1. 目的

规范低于最低库存或安全库存时的补购数量计算、采购合同起草、OA 审批、PO 发布、供应商确认、ASN、收料与关闭流程。任何虚拟员工不得绕过人工审批发布采购承诺。

## 2. 唯一职责

| 角色 | 唯一主责 |
|---|---|
| 库存安全虚拟员工 `WMS-INVENTORY-VIRTUAL-01` | 根据库存流水、阈值和已确认在途数量计算建议采购数量，并定期报告风险。 |
| 采购虚拟员工 `PURCHASING-VIRTUAL-01` | 接收建议数量，匹配合格供应商、MOQ、交期和参考价格，起草采购合同并提交 OA。不得擅自修改库存数量。 |
| PMC | 确认生产需求、停线风险和需求日期。 |
| 采购主管 | 审核供应商、价格、MOQ、交期和合同条款。 |
| 财务 | 按金额路由审核预算、付款条款、币种及税务风险。 |
| 工厂负责人 | 最终批准采购承诺。 |
| Hermes | 监督超时、缺字段和跨部门异常，不替代审批人。 |

## 3. 数量规则

建议采购数量的基础公式：

```text
基础建议数量 = max(0, 目标库存 − 可用库存 − 已确认在途数量)
```

- `可用库存`必须从已过账的 `inventory_transactions` 推导，不使用手工余额。
- `目标库存`优先使用最高库存；未配置最高库存时依次使用安全库存、最低库存。
- `已确认在途数量`仅包括已发布、已确认或部分收货 PO 的未收数量。
- 采购合同数量不得低于供应商 MOQ；配置包装倍数后必须向上取整。
- Hold、待 IQC、报废、冻结和过期库存不得计入可用库存。
- 缺少库存流水、供应商映射、MOQ、价格或币种时必须阻断并要求人工补充。

## 4. 合同与 OA 流程

1. 库存安全员工生成带时间戳的低库存报告和建议数量。
2. 采购员工只读取该建议数量，按已批准的物料—供应商关系分组。
3. 采购员工生成采购合同草稿，写明物料、数量、单位、参考单价、金额、交期、付款及交付条款。
4. 合同自动进入 `pending_approval`，并在 OA 建立审批任务。
5. 低金额合同：采购主管 → 工厂负责人。
6. 高金额合同：采购主管 → 财务经理 → 工厂负责人。
7. 任一步拒绝后合同转为 `rejected`，不得生成或发布 PO。
8. 全部批准后才允许生成 PO；PO 发布后同步到对应供应商门户。

## 5. 审批人检查清单

- 物料代码、名称、单位是否正确。
- 建议数量是否来自最新库存报告，是否扣除已确认在途。
- 供应商是否启用且该物料授权有效。
- MOQ、包装倍数、交期和目标到货日是否合理。
- 单价、币种、税费、付款和交付条款是否完整。
- 是否存在重复的开放合同、PO 或在途数量。
- 是否存在可替代物料或生产计划变化。

## 6. 异常与警告

- 无合格供应商：阻断合同，转采购寻源。
- 无参考价格：允许生成零金额草稿，但必须阻断最终批准并要求采购补价。
- 预计停线：P3 严重警告，同时通知 PMC、采购主管及工厂负责人。
- 审批或供应商确认超时：Hermes 升级，不自动批准。
- 供应商拒绝或无法满足交期：重新寻源并保留原审批记录。

## 7. 审计与关闭

OA 必须保留库存报告编号、虚拟员工任务编号、合同编号、审批人、审批时间、意见和最终 PO 编号。完成收料、IQC、三方匹配和供应商绩效记录后，采购闭环才能关闭。
