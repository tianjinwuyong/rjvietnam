# 非 IQC 物料管理闭环

## 定义

非 IQC 表示不需要专业来料质量检验，但仍必须完成基础收货验证。它与“非 SMT”是两个独立维度：

- 非 SMT：描述物料是否进入 SMT 工艺。
- 非 IQC：描述物料是否需要 IQC 专业检验。

## 管理分类

- 生产辅料
- 包装材料
- 设备备件
- 工具及工装
- 劳保用品
- 办公及行政用品
- 化学品
- 清洁用品
- 低值易耗品
- 其他

每类物料配置责任部门、消耗/借还/资产/危险品控制模式、最低库存、最高库存、补货点和领用审批等级。

IQC/非 IQC 分类新建或变更必须由质量经理、工程和采购共同批准，并保存修改前后版本。分类改变只对生效后的业务有效，不改写历史收货记录。

## 六项收货检查

1. 采购订单匹配
2. 供应商和物料匹配
3. 数量匹配
4. 外观及包装检查
5. 生产日期和有效期有效
6. 合格证及随货文件完整

任意一项失败，物料自动进入隔离状态和隔离数量，不得进入可用库存。

## 异常处置

隔离物料可分流为：

- 接收
- 冻结
- 供应商补货
- 退货
- 换货
- 接受数量差异
- 让步接收
- 报废

分流数量总和必须等于收货数量。接受差异、让步接收和报废必须附审批记录；目的岗位必须确认接收。

## 领用

每次领用必须绑定一种用途：

- 工单
- 设备
- 部门
- 员工
- 项目
- 成本中心

同时必须记录数量、申请人、审批人、仓库发料人和成本中心。申请人不能批准自己的申请。系统在发料事务中锁定库存并禁止负库存。

收货和领用请求必须携带唯一 `source_event_id`。网络重试或并发重复提交返回原业务结果，不得重复增加或扣减库存。

## 借还

工具、工装、资产和其他可回收物品采用借出—归还模式。记录唯一物品号、借用人、预计归还时间、实际归还时间和归还状态。

- 良好归还：恢复可用库存。
- 损坏或丢失：必须填写损失处理，不能静默关闭。
- 超期：进入预警队列。

## 系统权责

| 系统 | 权威数据 |
|---|---|
| WMS | 库存、库位、收货、发料、退料、借还、盘点 |
| 采购 | 采购订单、供应商、价格、补货、退换货 |
| MES | 生产工单、产线用途、生产消耗 |
| 维修 | 设备备件、维修工单、旧件回收 |
| HR/行政 | 员工、部门、劳保和办公用品额度 |
| 财务 | 成本中心、资产、费用、损失和扣款 |
| 3D | 显示、追踪和报警；不得修改或锁定业务 |

## 十项关单检查

1. 收货数量平衡
2. 所有差异完成处理
3. 领用绑定用途、责任人和成本中心
4. 可回收物品已经归还或完成损失处理
5. 退货、换货和补货交接已确认
6. WMS 与实物一致
7. MES、维修、HR/行政使用记录已同步
8. 财务费用、资产或损失已入账
9. 所有报警和异常已关闭
10. 审计记录完整

任一项失败，只能进入等待关单，不得正常关闭。

## 验收结果

2026-07-24 本机端到端测试通过：

- 六项检查合格的收货进入可用库存。
- 检查失败的收货自动隔离。
- 异常退货交接能够确认接收。
- 领用绑定明确用途和成本中心。
- 申请人自我审批被阻止。
- 发料扣减可用库存。
- 可归还工具完成借出和良好归还。
- 十项检查通过后正常关单。
- API 域标记为 `WMS`。
- 测试数据已清理。
