# Overview

The system manages the whole SMT factory flow:

```text
Customer PO
  -> Product / BOM
  -> Work Order
  -> Material Receiving
  -> IQC
  -> Storage
  -> Picking
  -> SMT Line Issue
  -> Feeder Binding
  -> SMT Production
  -> SPI / AOI / ICT
  -> Repair / Rework
  -> Finished Goods
  -> Shipment
  -> Finance / Accounting
  -> Traceability / Reports
```
