# 客户 PO 创建操作说明

## 入口

1. 打开 `http://192.168.6.155:5178/`。
2. 使用“蒙营”或 `MENG_YING` 登录，密码为 `my`。
3. 点击左侧 **PMC 工单**。
4. 点击顶部 **PO 管理**。
5. 点击右上角 **创建客户 PO**。

## 必填内容

| 字段 | 说明 |
|---|---|
| 客户 PO 号 | 客户订单的唯一编号，不允许重复 |
| 客户 | 从有效客户主数据中选择 |
| 产品 | 从有效产品主数据中选择 |
| 订单数量 | 必须大于 0 |
| 交付日期 | 客户要求的交付日期 |

填写完成后点击 **确认创建 PO**。

## 创建结果

- PO 状态自动设为 `confirmed`。
- 系统记录创建人、创建时间和创建内容。
- 新 PO 会立即出现在 **PO 管理** 列表。
- PMC 可以在 **创建工单** 页面选择该 PO 生成量产 WO。

## 完整闭环

```mermaid
flowchart LR
  A["创建并确认客户 PO"] --> B["PMC 创建 WO"]
  B --> C["计划审批与物料齐套"]
  C --> D["下发 MES 并生产"]
  D --> E["OQC 质量放行"]
  E --> F["发货过账"]
  F --> G["应收发票过账"]
  G --> H["客户付款"]
  H --> I["客户验收证据"]
  I --> J["六门禁全部 PASS"]
  J --> K["关闭 PO"]
```

## 关闭条件

必须全部满足：

1. 已关联工单；
2. 所有工单生产完成；
3. OQC 已放行；
4. 发货数量覆盖 PO；
5. 发票已过账且款项已结清；
6. 已提交客户验收证据。

PO 关闭后，禁止新增或修改关联工单、追加报工、转线、发货或开票。
