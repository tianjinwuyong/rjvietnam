母板 `20260720131301` 的 SN `5G5705583A`：

- `ictNg=true`
- `ictResults=["FAIL"]`
- `fctResults=["PASS"]`
- 原合并字段错误显示 `result="PASS"`

这会让 FCT PASS 隐藏尚未复活的 ICT NG，不符合闭环规则。

- ICT 与 FCT 分别维护自己的 NG 状态。

- 只有对应工站的有效复测/复活结果清除其 NG 标记，并且 ICT/FCT 两个标记都清除后，总结果才为 PASS。
- 历史 ICT/FCT 结果继续永久保留。
