# WMS Glossary

Maintain shared definitions here so agents use the same language.

| Term | Definition | Source/issue |
|---|---|---|
| staging-only | A disposable, non-production execution boundary used for tests and evidence. | RJV-133 |
| durable evidence | A file, artifact, commit, or captured test output that another person can inspect later. | RJV-133 |
| knowledge loop | Search prior knowledge, execute, verify, record evidence, record the lesson, and link it back to the task. | RJV-138 |
| live run | A currently executing Paperclip agent run; it is not proof of successful delivery. | RJV-133 |
