# PDA 物料上料操作指南

## 概述

SMT 智能料架系统的核心操作环节。通过 PDA（或 Web 界面）扫描物料卷盘条码，系统自动匹配 Feeder 槽位并完成上料确认，全流程可追溯。

---

## 术语

| 术语 | 说明 |
|------|------|
| **Feeder** | SMT 贴片机供料器，每台机器有多个槽位（如 F01-F12） |
| **Feeder Loading** | 将物料卷盘装载到 feeder 槽位 |
| **Fool Proof Rule** | 防错规则，绑定物料编码/卷盘条码到指定槽位 |
| **Smart Rack** | 智能料架，带 LED 引导定位功能 |
| **BOM** | 物料清单，工单所需的全部物料及数量 |
| **Shortfall** | 物料缺口 = 工单需求数量 - 已上料数量 |

---

## 操作界面

路径：`MES → 物料上料（Material Loading）`

入口前需先选择产线：`L001`（SMT 一线）、`L002`（SMT 二线）、`L003`（SMT 三线）

---

## 标准上料流程

### 第一步：输入工单条码

```
操作员：在工单输入框扫描或手动输入工单条码（如 26061010008）
       或点击快捷按钮快速选择历史工单
系统：  读取该工单的 BOM 需求，匹配防错规则
显示：  全部 Feeder 槽位列表（站位 / 槽位 / 物料 / 预期卷盘）
```

### 第二步：查看上料计划

```
系统：  根据防错规则生成上料清单
       已上料的槽位显示 ✓ verified（绿色）
       未上料的显示 ○ pending
       校验失败的显示 ✗ error（红色）

操作员：查看每个槽位需要的物料编码和预期卷盘条码
```

### 第三步：扫描卷盘条码（核心操作）

```
操作员：用 PDA 扫描物料卷盘条码
条码格式：R- 开头或 REEL- 开头均可
示例：R-0603-10K-1

系统自动匹配逻辑（按优先级）：
  1. 扫描的卷盘条码 → 匹配预期卷盘条码
  2. 扫描的物料编码 → 匹配预期物料编码
  3. 均无匹配 → 默认匹配第一个 pending 槽位
```

### 第四步：防错校验

```
系统：根据 Fool Proof Rule 进行校验
  • material 类型：卷盘条码包含物料编码 → 通过
  • reel 类型：卷盘条码 = 预期卷盘条码 → 通过
  • both 类型：以上两者均需匹配

  校验通过 → 自动调用 POST /mes/feeder-bindings
  校验失败 → 槽位置 error，提示「扫码与预期物料不符」
```

### 第五步：重复扫描直到全部完成

```
操作员：对每个 pending 槽位重复 第三步 → 第四步
进度条：实时显示 verified / total 和百分比
全部完成后：「确认完成」按钮亮起
```

### 第六步：确认完成

```
操作员：点击「确认完成」
显示：  上料汇总表（槽位 / 物料 / 实际卷盘 / 操作人 / 时间）
       可导出或截图存档
```

---

## 防错规则

| 规则类型 | 触发条件 | 校验逻辑 |
|----------|----------|----------|
| `material` | 扫描物料编码 | 卷盘条码包含该物料编码则通过 |
| `reel` | 扫描卷盘条码 | 卷盘条码完全等于预期则通过 |
| `both` | 以上两者 | 物料编码 + 卷盘条码均匹配才通过 |

**错误提示示例：**
```
验证失败：R-0603-10K-1 → 预期物料 PCB-AURORA-CTRL
（表示该卷盘与当前槽位要求不符，不可上料）
```

## 进度状态说明

| 状态 | 图标 | 含义 |
|------|------|------|
| `○ pending` | 灰色圆圈 | 槽位待上料 |
| `✓ verified` | 绿色勾 | 物料已上料成功 |
| `✗ error` | 红色叉 | 扫码物料与预期不符，需重新处理 |

## API 接口

| 端点 | 方法 | 说明 |
|------|------|------|
| `/mes/feeder-bindings` | POST | 绑定物料到 Feeder 槽位（写入 feeder_bindings） |
| `/mes/feeder-bindings` | GET | 查询已存在的绑定记录 |
| `/mes/feeder-loading` | POST | 确认上料（写入 feeder_loading_events） |
| `/mes/feeder-loading/:workOrderCode` | GET | 查询工单已上料记录 |
| `/pmc/work-orders/:code/lock` | POST | 锁定工单（多PDA协同） |
| `/pmc/work-orders/:code/unlock` | POST | 解锁工单 |
| `/pmc/work-order-material-status` | GET | 获取 BOM 物料需求和缺口 |

---

## 多 PDA 协同

```
同一工单：最多 10 台 PDA 可同时锁定，同时上料
         各操作员独立扫描不同槽位，互不干扰
单人限制：每名操作员同时只能持有 1 个工单
         切换工单前须先解锁当前工单
强制解锁：工长/PMC 可后台强制解锁（force=true）
```

---

## 故障处理

| 情况 | 处理 |
|------|------|
| 扫码后置 error | 确认物料是否正确，更换正确卷盘后重新扫描 |
| 物料不在预期槽位 | 检查防错规则配置，或联系工艺工程师修正规则 |
| 工单被其他 PDA 锁定 | 等待其他操作员完成后再锁定 |
| LED 不亮 | 检查料架连接，刷新页面重新触发 LED 引导 |
| 扫码格式不对 | 支持格式：R- 开头、REEL- 开头 |
