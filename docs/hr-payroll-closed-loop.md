# 员工工资核算、审批、发放与财务闭环

## 标准流程

1. 人事确认当月考勤、请假、加班、奖励、扣款、保险、税费和生效调薪。
2. 系统建立工资批次并冻结计算来源时间。
3. 系统从逐人工资记录生成工资单，保存完整计算快照和来源核对结果。
4. 人事复核人数、应发、扣款、税保和实发金额并批准。
5. 财务复核资金、银行资料和总额并批准。
6. 财务按员工支付方式进行银行发放或现金发放。
7. 银行发放必须保存银行流水号；现金发放必须由员工工牌签领，可增加见证人工牌。
8. 失败或退回的付款不得计为已发放，必须处理后重新发放。
9. 所有员工完成发放或签领后，系统生成财务交接数据并锁账。
10. 锁账后的工资不能直接修改；需要调整时必须在后续月份建立补发或扣回事项。

## 控制原则

- 工资制作、人事审批、财务审批和付款必须分阶段完成。
- 未经人事批准，财务不能批准；未经财务批准，不能付款。
- 现金交给员工不等于完成，员工签领后才完成。
- 有任何未支付、失败、退回或未签领项目时，工资批次不能锁账。
- 每次计算保存工资记录快照，之后源数据发生变化也不会悄悄改变已审批工资。
- 银行账号使用支付令牌和尾号管理，不在普通业务表中保存完整明文账号。
- 每一步写入工资审计表，保留操作者、时间、金额和状态变化。

## 财务报表

- 月度工资人数、应发工资、扣款及税保、实发工资
- 已发、未发、失败、退回、现金待签领
- 员工工资单及发放方式
- 财务工资费用、员工应付、代扣税款、保险应付交接
- 年度工资趋势和月份对比

## 系统位置

管理系统 → 人事 → **工资审批与发放**

核心数据表：

- `salary_records`：逐人工资计算结果
- `hr_payroll_batches`：月度工资批次
- `hr_payroll_items`：工资单和计算快照
- `hr_payroll_source_reconciliations`：人事制作工资核对
- `hr_payroll_approvals`：人事、财务审批
- `hr_payroll_payments`：银行或现金付款
- `hr_payroll_cash_receipts`：员工现金签领
- `hr_payroll_accounting_exports`：财务交接
- `hr_payroll_audit`：全程审计
- `hr_employee_payment_profiles`：员工支付方式与银行令牌
