# SMT 物料闭环压力验收规则

1. PDA、WMS、MES、NPM绑定冲突时冻结相关 Slot；设备不支持单 Slot 停止时停机。
2. MSD 超时后冻结卷料及超时后生产的全部在制品，由质量决定后续处置。
3. SMT 数量关单实行零差异；每一件差异必须有退料、抛料、测试、转移或报废依据。
4. 替代料必须有工程替代关系及质量批准，线长不能单独放行。
5. 离线授权最长30分钟；延长必须使用厂级双人一次性应急许可。
6. 相同设备事件编号和相同内容只累计一次；相同编号不同内容为 CRITICAL 冲突。
7. 退料2分钟提醒、15分钟升级、30分钟冻结；WMS扫码接收前不得恢复可用库存。
8. 物料分类变更必须经 WMS、工程、PMC 审批，只对生效后的新业务有效。
9. 未完成退料、未匹配消耗、抛料、BOM差异或离线审查时，禁止正常关单。
10. 按事实类型确定权威：库存=WMS，扫描=PDA，执行=MES，消耗=NPM，放行=QUALITY。

任何冲突都保留原始记录，禁止覆盖。处理结果必须记录操作者、时间、原因、旧值、新值和批准链。
