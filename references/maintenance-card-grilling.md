# 设备保养卡 (Maintenance Card) — Grill Session

> 2026-07-25 | 越南瑞晶SMT工厂 | 用 `/grill-me` 方法逐个决策

---

## Q1: 保养卡定位

**结论 ✅ 已确认：D — 完整功能**
- 每个工位设备生成独立保养卡（纸质可打印 + 电子版）
- 包含：设备基础信息 + 5级保养标准 + 检查项清单 + 历史记录 + 签名栏
- 班组长/技术员按卡执行 → PDA扫码打卡 → 系统记录实际执行时间
- 支持月度/季度/年度汇总页

---

## Q2: 保养卡内容字段

**结论 ✅ 已确认：D — 全功能**
- 设备信息区：设备编号/名称/型号/制造商/序列号/QR码
- 当前位置：产线+工位+区域
- 责任人：设备负责人+班组长+维修技术员
- 设备参数：功率/电压/速度/生产节拍
- 5级保养项目清单（日常/一级/二级/三级/季度/年度）
- 每项检查项：标准值/实际值/判定/备注
- 最近一次保养：日期+执行人+结果
- 下次保养：计划日期+类型+触发条件
- 签名栏：执行人+审核人+日期
- 历史记录摘要：最近6次保养结果

---

## Q3: 5级保养标准定义

**结论 ✅ 已确认：D — 完整分级定义**
- L1日常：每天/每班次（操作员执行，5-10分钟）
- L2一级：每周（技术员执行，30-60分钟）
- L3二级：每月（维修技师，2-4小时）
- L4三级：每季度（工程师+外协，半天-1天）
- L5四级：每年或按运行小时（厂家精度校准+大修）
- 每级：检查项目数/预计工时/所需工具/所需备件/安全注意事项/验收标准

---

## Q4: 保养卡呈现形式

**结论 ✅ 已确认：D — 纸质打印 + 电子PDA + 电子看板三轨并行**
- 纸质打印：贴在设备旁边，执行时勾选，支持A5/卡片式
- PDA电子版：扫QR码 → 显示设备保养卡 → 执行一项勾一项 → 拍照记录
- 电子看板：保养日历视图 + 逾期预警 + 统计报表

---

## Q5: PDA扫QR触发保养任务

**结论 ✅ 已确认：D — 全链路闭环**
- 扫QR → 显示设备卡 → 系统判断是否有到期保养任务
- 有到期任务 → 锁定设备状态（待机/报警）→ 强制执行保养
- 无到期任务 → 正常显示设备信息 + 最近保养记录
- 执行过程：检查项逐项打卡 → 需要时输入测量值 → 异常时触发报修
- 完成：拍照 → 签名 → 系统记录实际执行时间/工时/备件使用

---

## Q6: 检查项模板管理

**结论 ✅ 已确认：D — 模板库+设备类型+保养级别三维管理**
- 模板库：每种设备型号维护一套检查项模板
- 设备类型关联：SMT贴片机/Panasonic NPM/回流焊/SPI/AOI等各自独立模板
- 保养级别：L1/L2/L3/L4/L5各自独立检查项清单
- 支持复制/导入/导出/版本管理
- 检查项类型：开关/测量值（数值范围）/目视检查/清洁/润滑/紧固/校准/更换

---

## Q7: 保养任务触发条件

**结论 ✅ 已确认：D — 双触发优先模式**
- 日历触发：按固定日期（每月1日/每周一/每季度首日）
- 运行时间触发：按累计运行时长（每1000小时/每5000小时等）
- 两者独立计算，哪个先到触发哪个
- 支持双重触发（L3及以上保养用）
- 优先级：紧急故障 > 运行时长到期 > 日历到期

---

## Q8: 执行人员资格要求

**结论 ✅ 已确认：D — 级别+证书+MES门禁**
- L1日常：操作员（基础培训即可，无需证书）
- L2一级：技术员（设备内部培训证书）
- L3二级：维修技师（电工证/焊工证等特种作业证）
- L4三级：工程师+厂家授权（精度校准需原厂证书）
- L5四级：厂家工程师（原始证书+原厂授权）
- MES系统校验：员工扫码 → 查证书有效期 → 无证则禁止执行该级别保养

---

## Q9: 保养中发现异常处理

**结论 ✅ 已确认：D — 分级+Andon+派工+闭环**
- 发现异常 → 选择异常等级（停机紧急/影响品质/可观察）
- 停机紧急：触发Andon+锁定设备+自动派工给维修技术员
- 影响品质：生成维修工单+影响分析+挂起该批次
- 可观察：记录到保养报告+下次跟踪
- 异常关联：可关联到设备BOM备件消耗记录
- 异常处理结果回填保养卡

---

## Q10: 保养完成验收流程

**结论 ✅ 已确认：D — 三重验证+首件**
- 第一重：执行人自检 → 拍照 + 签字
- 第二重：班组长现场确认 → 检查关键项 + 签字
- 第三重：工程师精度验收（L3及以上）→ 首件验证 + 数据记录
- 合格 → 系统关闭保养任务 + 更新设备状态为"运行中"
- 不合格 → 打回重做 + 记录不符合项

## Q11: 保养卡历史记录管理

**结论 ✅ 已确认：D — 全量档案+分析+导出**
- 每次保养生成一条执行记录（含所有检查项结果+照片+签名+工时）
- 历史版本：永久保存，支持按时间/设备/人员/保养级别筛选
- 统计分析：保养合格率/异常率/工时趋势/备件消耗/设备MTBF
- 导出：PDF保养报告（按设备/月度/季度）+ Excel明细
- 逾期记录：未按时执行的保养记录单独标记 + 原因记录

## Q12: 设备详情页保养卡展示

**结论 ✅ 已确认：D — 完整仪表盘式**
- 设备状态区：运行/待机/保养中/故障（颜色标识）
- 保养概览：上次保养日期/L1-L5各举最近一次/下次到期时间

## Q17: 保养卡打印触发和更新机制

**结论 ✅ 已确认：D — 全自动按需打印+到期自动提醒**
- 新设备投产 → 系统自动生成保养卡 → 打印贴附
- 设备信息变更（移机/换型号/换责任人）→ 自动触发新版打印
- 模板修订 → 系统批量更新 → 相关设备卡自动重新打印
- 纸质卡污损/丢失 → PDA一键申请补打 → 审批后打印
- 打印记录：谁在何时打印了什么版本，系统留痕

## Q18: 纸质卡与电子记录同步机制

**结论 ✅ 已确认：D — 纸质为基础+电子归档+防伪水印**
- 纸质卡是执行依据（贴在设备旁），电子记录是归档凭证
- 执行时：纸质卡勾选 → 之后统一录入PDA或PC端归档
- 每次归档：纸质卡拍照 + QR码关联 → 生成电子档
- 版本号：纸质卡有唯一序列号，与电子版本号一一对应
- 防伪水印：纸质卡打印时带设备QR码和版本号，防止伪造
- 不一致时：以电子归档时间戳为准，纸质卡作为辅助证据

---

## Q19: 保养卡与设备档案关联方式

**结论 ✅ 已确认：D — 设备生命周期全绑定**
- 设备档案号 = 保养卡编号前缀（如：EQ-2024-001-L1）
- 设备每次大修/改造/移机 → 保养卡版本升级（v1→v2）
- 设备报废 → 保养卡封存归档，不可再用
- 设备转让/借调 → 保养卡跟随设备走，记录移交过程
- 备件更换记录 → 同时体现在设备档案时间线+保养卡历史页

## Q20: 保养卡在设备维护体系中定位

**结论 ✅ 已确认：D — 体系核心载体**
- 保养卡是设备TPM体系的核心执行工具（不是孤立的一张纸）
- 日常点检（L1）→ 保养卡是执行标准和记录载体
- 定期保养（L2-L5）→ 保养卡是计划、执行、验收的闭环凭证
- 故障维修 → 维修工单关联保养卡（判断是否因保养不当导致）
- 设备改进 → 保养卡记录的问题趋势 → 反馈到设备改造设计
- 体系循环：数据收集 → 分析 → 改进 → 更新保养标准 → 下一个循环
