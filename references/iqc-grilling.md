# IQC 来料检验 Grill 结论
> 越南瑞晶 SMT 工厂 | 2026-07-25 | 19 Qs 全部确认 D

---

## Q1: 核心流程
**结论 ✅：** D — 全功能（测量数据+数量处置+批次追溯+供应商绩效联动）

## Q2: 触发方式
**结论 ✅：** D — 全自动 + 跨系统联动
- 来料自动送检（供应商等级矩阵+物料类别）
- IQC 结果自动回写 WMS 批次状态
- MES 工单自动解锁/锁定
- 供应商绩效自动更新
- 超时自动升级（IQC 组长+工程双签）

## Q3: 免检白名单
**结论 ✅：** C — 分级免检
- 供应商等级 A + 物料免检次数联动
- 免检次数用尽自动触发强制 IQC
- 免检到期需重新审批（IQC 组长审批）
- 不做 D（风险系数需大量历史数据，上线初期数据不足）

## Q4: AQL 抽样方案
**结论 ✅：** C — 动态 AQL
- 连续3批合格 → 自动降级（AQL 1.0→2.5）
- 连续2批不合格 → 自动升级（AQL 1.0→0.65）
- 免检次数同步联动
- 配合 GB/T 2828.1 抽样表自动查表

## Q5: 判定结果处置
**结论 ✅：** D — 全处置 + 财务联动
- 合格入库
- 不合格触发供应商扣款/索赔
- IQC 成本入工单
- 供应商绩效分数实时更新
- 批次追溯串起整条链

## Q6: MES/WMS 集成
**结论 ✅：** D — 全链路联动
- IQC 合格 → WMS 解锁 + MES 工单继续 + 批次信息写入 MES
- 不合格 → WMS 锁定 + MES 工单暂停 + 自动生成待处理任务
- 超时未处理自动升级
- IQC 在制品可视化
- 实时 Andon 报警
- IQC 超时看板

## Q7: PDA 移动端
**结论 ✅：** D — PDA 全移动 + 离线
- 扫码 → 查 IQC 任务 → 查 AQL 抽样表 → 逐件检验 → 缺陷录入 → 拍照 → 判定 → 特采/退货审批 → 结果回写 WMS+MES
- 离线暂存（无 WiFi 区域）→ 联网自动同步
- 扫码枪/相机/打印全支持
- 多人协作（多个检验员同批次）
- IQC 超时预警推送

## Q8: 报表中心
**结论 ✅：** D — 完整 + 管理驾驶舱
- 质量成本分析（IQC 失败成本）
- 供应商 PPM 趋势
- IQC 效率 KPI（人均检验批次数/平均时长）
- 实时 Andon 看板
- 导出 Excel/PDF + 自定义报表

## Q9: 检验项目
**结论 ✅：** D — 深度 + SPC
- 全量检验参数量化
- 测量数据入 SPC 控制图
- CPK 计算
- 超限自动报警
- 和历史数据对比趋势分析
- 检测设备定期校准提醒

## Q10: 人员配置
**结论 ✅：** D — 分级 + 轮换
- 检验员做普通物料
- IQC 工程师做关键件/SMT 物料
- IQC 组长做特采审批
- 工程做技术判定
- 检验员轮换制度（防止舞弊）
- 检验员绩效考核
- 资质认证（计量证书/光学检测证书）
- IQC 组长有跨厂区审批权限

## Q11: 批次追溯
**结论 ✅：** D — 全追溯
- SN 级追溯（每件物料可查）
- 缺陷样品留样影像（Before/After）
- 同批次所有流向（成品 SN + 客户）
- 跨工厂追溯（越南↔中国工厂）
- 海关记录（进口物料）

## Q12: 供应商质量联动
**结论 ✅：** D — 完整 + 闭环
- Critical → 立即停货 + 紧急8D
- Major → CAPA + 改善追踪
- Minor → 记录 + 警告
- CAPA 闭环验证（IQC 下次来料复查）
- 供应商 PPM 趋势分析
- 供应商门户自动推送（越南/中国语言）
- CO/CQ 证书自动校验
- IQC 成本入供应商账单
- 年度供应商评级自动重评

## Q13: 特采审批流
**结论 ✅：** D — 完整 + 财务联动
- 小额少量 → IQC 组长
- 大额 → 加 PMC
- Critical → 加厂长
- 审批时效超时自动升级
- 特采金额超阈值 → 财务总监审批
- 采购确认 + 供应商索赔谈判记录
- 特采成本入批次/工单
- 年度特采汇总报表
- 超次数特采 → 强制实地审核供应商

## Q14: Andon 和实时监控
**结论 ✅：** D — 完整 + 智能预警
- Critical 不良 → 立即 Andon 灯 + 声音报警 + 停止入库 + 触发紧急8D + 供应商电话通知 + 检验员10分钟内响应
- 超时前自动预警（提前2小时）
- 免检即将到期预警
- 检验员负荷预警（超负荷自动派单）
- 供应商来料预报（提前24h）和 IQC 预约系统联动
- IQC 效率实时大屏

## Q15: 界面呈现
**结论 ✅：** D — 完整 + 3D 集成
- 仓库物理布局可视化（哪个区/货架）
- 免检白名单状态可视化
- IQC 负荷热力图
- 实时 Andon 灯
- 质量驾驶舱大屏（越南瑞晶工厂展厅级）
- 支持 TV/LED 大屏
- 导出大屏截图

**结论 ✅：** D — 深度协同
- IQC/OQC/IPQC 共用 SPC 控制图
- IQC Critical → 自动创建 QMS 客诉 + 紧急8D

- 质量成本（QMS Phase 3）自动汇总 IQC 失败成本
- IQC 判定记录作为 QMS 审核证据
