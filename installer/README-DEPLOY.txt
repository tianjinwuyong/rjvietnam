WMS 仓库管理系统 1.0 —— 部署说明
==================================================

一、安装前提
--------------------------------------------------
  · Windows 10 / 11 或 Windows Server 2016 及以上，64 位
  · 至少 4GB 内存、10GB 空闲磁盘（数据另计）
  · 安装过程中需要管理员权限（安装程序会自动申请提权）

二、安装步骤
--------------------------------------------------
  1. 把 WMS-Setup-1.0.exe 拷到新服务器上（U 盘或内网共享均可）
  2. 右键 → 以管理员身份运行
  3. 选择安装目录（默认 C:\WMS，建议保持默认，路径不要含中文和空格）
  4. 一路下一步，安装程序会自动完成：
       · 生成随机数据库口令与 JWT 密钥（写入 .env）
       · 初始化 PostgreSQL 数据目录（端口 5433，仅本机访问）
       · 注册 PostgreSQL 服务并启动
       · 创建空库 wms，建 78 张表
       · 导入预置数据：系统用户与角色、系统参数、IQC 检验模板
       · 注册 WMS 应用服务并启动
       · 放行防火墙 3000 / 3443 端口
  5. 安装完成后桌面会出现「WMS 仓库管理系统」快捷方式

三、安装后访问
--------------------------------------------------
  本机：    http://127.0.0.1:3000
  局域网：  http://服务器IP:3000
  手机/PDA：https://服务器IP:3443
            （扫码、拍照等浏览器能力要求 HTTPS；
              首次访问需安装证书，页面会引导下载）

  登录账号：沿用原系统的账号与密码
            本包预置 14 个账号（含系统管理员 admin 与 RJ8888）、21 个角色，
            密码哈希随包携带，口令请向原系统管理员索取。
  ⚠ 首次登录后建议在「系统管理 → 用户管理」里重置不再需要的账号。

  想做「纯空库」部署（默认 admin / admin 登录）：
      安装前删除 scripts\seed-data.dump，安装程序会自动跳过预置数据导入。

  安装完成后，安装目录下会生成 install-info.txt，
  里面记录了本机所有可用访问地址，可直接发给使用人。

四、服务与启停
--------------------------------------------------
  安装自带两个 Windows 服务，默认开机自启、崩溃自动重启：
      WMS-PostgreSQL    数据库
      WMS-App           应用

  命令行（管理员）：
      net start WMS-App          启动
      net stop  WMS-App          停止
      sc query  WMS-App          查状态

  也可以直接执行安装目录下的脚本：
      scripts\start-wms.cmd
      scripts\stop-wms.cmd
      scripts\status-wms.cmd

五、数据与备份
--------------------------------------------------
  · 数据库文件在 安装目录\pgdata，请把整个目录纳入备份计划
  · 备份命令示例（管理员命令行）：
      "C:\WMS\pgsql\bin\pg_dump.exe" -h 127.0.0.1 -p 5433 -U postgres -Fc -f D:\backup\wms.dump wms
    （口令见安装目录 .env 中的 DB_PASSWORD）
  · 恢复：先用 pg_restore 恢复到新库，再改 .env 的 DB_NAME 指向它

六、本安装包包含什么 / 不包含什么
--------------------------------------------------
  已预置（来自原系统导出的干净基线）：
    · 系统用户 14 个 + 角色 21 个（密码沿用原系统，哈希格式 pbkdf2）
    · IQC 检验模板 24 个（含 31 条检验项目、6 条标准项目库）
    · 系统参数 19 项（公司名、仓别编码、IQC 目标等）
    · 系统自建的默认良品仓 01 与不良品仓 NG01（各含库位）

  已清空（需使用方重新导入或建立）：
    · 物料主数据、供应商、BOM —— 全部为空
    · 库存台账与全部出入库流水
    · IQC 检验执行数据：检验批次、检验报告、检验严格度与计数、严格度转移日志
    · 收货 / 发料 / 工单 / MRB / 盘点 / 退货 / 销售等业务单据
    · 操作日志、MES 同步日志、OA 事件队列
    · 除 01 / NG01 之外的其他仓库与库位

  ⚠ 安装后第一次使用前，请先导入物料主数据（系统管理 → 物料导入），
     并根据实际需要增补仓库与库位。

七、升级
--------------------------------------------------
  重新运行新版安装包，安装到同一目录即可：
  · 已有的 .env（数据库口令、JWT 密钥）会原样保留
  · 已有的 pgdata 不会被重建
  · 表结构初始化脚本是幂等的，只补缺不改数据

八、卸载
--------------------------------------------------
  控制面板 → 程序和功能 → WMS 仓库管理系统 → 卸载
  · 会停止并移除两个 Windows 服务
  · 默认保留 pgdata，需彻底清除请手动删除该目录

九、常见问题
--------------------------------------------------
  Q: 安装时提示端口被占用？
  A: 本包固定使用 5433（数据库）、3000（HTTP）、3443（HTTPS）。
     请先停掉占用这些端口的程序再装。

  Q: 服务启动失败怎么排查？
  A: 看 安装目录\logs\ 下的 postgres-err.log / app-err.log；
     也可执行 sc query WMS-App 看服务状态。

  Q: 手机扫码打不开摄像头？
  A: 必须用 https://IP:3443 访问，并按页面提示安装证书。

  Q: 忘记 admin 密码了？
  A: 用 psql 连接后重置 sys_account 的 password_hash，
     或联系实施人员处理。
