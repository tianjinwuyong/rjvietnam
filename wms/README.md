# WMS 仓库管理系统 — 绿色免安装版

> **本版本已内置全部依赖（node_modules）与构建产物（dist），拷贝过去配置好即可启动，无需联网、无需执行 npm install / npm run build。**
>
> ⚠️ 唯一的外部依赖：目标机器仍需安装 **Node.js 22+**（这是运行环境，无法打进包里）。

## 二、部署三步

### 第 1 步：确认目标机器已装 Node.js 22+

```bash
node -v      # 应输出 v22.x.x 或更高
```

若未安装，请到 https://nodejs.org/ 下载 LTS 版安装。

### 第 2 步：启动（首次运行会让你填数据库密码）

**双击 `启动.bat`** 即可。

**首次运行**时，启动器会先问你选哪种配置方式：

```
    [1] 交互式输入（推荐，逐项询问）
    [2] 打开记事本手动编辑配置文件

  直接回车 = 使用方式 1
```

**方式 1（交互式）** 会逐项询问，直接回车用默认值：

```
  1/6 数据库地址 (localhost):       ← 回车用默认
  2/6 数据库端口 (5432):            ← 回车用默认
  3/6 数据库用户名 (postgres):      ← 回车用默认
  4/6 数据库名 (wms):               ← 回车用默认
  5/6 服务端口 (3000):              ← 回车用默认
  6/6 数据库密码:                   ← 【必填】目标机器的 PostgreSQL 密码
```

**方式 2（记事本）** 会生成配置文件模板并打开记事本，你只需改 `DB_PASSWORD` 一行，保存关闭即可。

**JWT 密钥两种情况都由程序自动生成**（48 字节随机），无需你操心。

配置完成后启动器会：**验证数据库连通性**（连不上会给出排查清单）→ 自动建表建账号 → 启动服务。

> 想重新配置：删除 `.env` 文件后重新双击 `启动.bat` 即可。

### 第 3 步：数据库准备

目标机器需要有一个 PostgreSQL 数据库。若尚未创建：

```sql
-- 用 psql 或任意客户端连接后执行
CREATE DATABASE wms;
```

> 首次启动时会自动建表、建默认角色、建管理员账号（admin / admin），无需手工执行任何 SQL。

## 六、重要提示

1. **`node_modules` 与 `dist` 不可删**：这是本版本「免安装」的核心，删除后就变成标准部署包了。
2. **不要跨机器直接复制 `node_modules`**：本包的 `node_modules` 是在**当前这台机器**上安装的。如果目标机器与本机操作系统、Node 版本差异较大，可能出现原生模块不兼容，此时在目标机器执行一次 `npm install` 即可修复。
3. **`node_modules` 内含本机绝对路径**：若把本包拷到**不同盘符/路径**（例如从 D 盘拷到 E 盘），`.bin` 下的启动脚本可能需要重新生成。这种情况下在目标机器执行一次 `npm install` 最稳妥。
4. **服务窗口不能关闭**：关闭窗口即停止服务。
5. **PDA 扫码需 HTTPS**：普通安卓设备需先访问 `/cert` 安装证书；工业 PDA 用扫描枪则用 HTTP 即可。
6. **服务器请用固定 IP**：否则重启后 IP 变化，客户端与 PDA 都要重新配置。

## 七、常见问题

| 现象 | 处理 |
|------|------|
| 提示「未检测到 Node.js」 | 安装 Node.js 22+ 后重试 |
| 提示「未找到 node_modules」 | 拷贝不完整，重新完整拷贝本目录 |
| 构建失败 / 提示模块缺失 | 在目标机器执行 `npm install` 补齐依赖 |
| **提示「数据库连接失败」** | 说明向导里填的密码/地址不对。删除 `.env` 后重新双击 `启动.bat`，向导会重新询问 |
| 数据库初始化失败 | 检查 PostgreSQL 是否启动、密码是否正确、`wms` 库是否已创建 |
| 想改数据库配置 | 删除 `.env` 后重新运行 `启动.bat`（向导会重新询问），或用记事本直接改 `.env` |
| 端口被占用 | 删除 `.env` 重新运行向导并换个端口，或结束占用进程 |
| 局域网其他电脑打不开 | 放行防火墙 3000/3443 端口，确认 `SERVER_HOST=0.0.0.0` |
| 页面显示 `xxx.yyy` 键名 | 前端语言包缺键，联系开发人员补充 |

**防火墙放行命令（管理员 PowerShell）：**

```powershell
netsh advfirewall firewall add rule name="WMS-HTTP-3000" dir=in action=allow protocol=TCP localport=3000
netsh advfirewall firewall add rule name="WMS-HTTPS-3443" dir=in action=allow protocol=TCP localport=3443
```
