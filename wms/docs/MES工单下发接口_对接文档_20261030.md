# MES → WMS 工单下发接口 · 对接文档

**版本**：v1.0　**日期**：2026-10-30　**提供方**：MES（192.168.6.27:8080）
**使用方**：WMS（192.168.6.160:3000）

---

## 一、这套接口解决什么

现在 WMS 有库存，但拿不到 MES 的工单，仓库就不知道「哪张单要备什么料、备多少」。
这套接口把 **工单 + 领料需求** 以标准 JSON 给出去，两种用法定一条即可：

| 通道 | 谁主动 | 需要对方做什么 | 建议 |
|---|---|---|---|
| **拉（推荐）** | WMS 定时来调 | 只写一个 HTTP 客户端（定时任务），不用改服务端 | ✅ 先上这条，今天就能通 |
| 推（可选） | MES 主动 POST | 对方要先有接收接口（`POST /api/mes/v1/mo`） | 接口做好后打开，MES 每 5 分钟推变化 |

两条通道的 **payload 完全一样**，都是 `{"event":"mo.upsert","sentAt":"...","data":{...工单详情...}}`。

---

## 二、连接与鉴权

```
Base URL : http://192.168.6.27:8080/api/itf/wms
鉴权     : 请求头  X-Api-Key: <密钥>
```

密钥在 MES「订单管理 → 工单下发 WMS」页面右上可直接复制。**重置会让旧密钥立即失效**，两边要同步改。

> 说明：这套密钥只用于「MES 给 WMS 的工单接口」，与 MES 自己的登录令牌（X-Token）无关，也不需要 MES 账号。

---

## 三、接口清单

| # | 方法 | 路径 | 用途 |
|---|---|---|---|
| 1 | GET | `/ping` | 探活 + 看服务时间 |
| 2 | GET | `/mo` | **工单清单**（支持增量、分页、按产线/PO/状态过滤） |
| 3 | GET | `/mo/{moNo}` | 工单详情（含领料明细） |
| 4 | GET | `/mo/{moNo}/materials` | 只取领料需求（备料/发料用） |
| 5 | GET | `/issue/pending` | **待领料工单**（仓库轮询这个最省事） |

### 3.1 探活

```
GET /api/itf/wms/ping
X-Api-Key: mes-xxxxxxxx
```
```json
{
  "code": 0,
  "message": "ok",
  "requestId": "…",
  "data": { "service": "ruijing-mes", "ok": true,
            "serverTime": "2026-10-30 23:58:12", "utcOffset": "+07:00" }
}
```

### 3.2 工单清单

```
GET /api/itf/wms/mo?updated_since=2026-10-01T00:00:00&page=1&page_size=50&only_open=true
```

| 参数 | 说明 |
|---|---|
| `updated_since` | 增量起点。接受 `2026-10-01`、`2026-10-01 08:00:00`、`2026-10-01T08:00:00Z`。**建议首次全量、之后用上次最后一条的 `updatedAt` 作为起点** |
| `page` / `page_size` | 默认 1 / 50，`page_size` 上限 500 |
| `only_open` | `true` 时排除已完工/已关闭/已取消 |
| `status` | 按工单状态精确过滤，如 `生产中` |
| `line_code` | 产线，如 `SMT-L01` |
| `po_no` / `cust_code` / `wo_type` | 按 PO / 客户 / 工单类型过滤 |

真实响应（已截断，`total` 表示符合条件的总数）：

```json
{
  "code": 0,
  "message": "ok",
  "requestId": "741d1588a25049069f711c07b3201580",
  "data": {
    "total": 8, "page": 1, "pageSize": 1, "hasMore": true,
    "items": [{
      "moNo": "26101001204",
      "woType": "包装",
      "productCode": "2.01.00.55.0022",
      "productName": "EPS48R1-36",
      "productModel": "EPS48R1-36",
      "spec": "",
      "unit": "PCS",
      "panelCount": 12,
      "planQty": 50.0,
      "outQty": 0.0,
      "ngQty": 0.0,
      "lineCode": "PACK-L01",
      "status": "已排产",
      "poNo": "", "poLine": "1",
      "custCode": "NB08",
      "planStart": "2026-10-26", "planEnd": "2026-11-01",
      "actualStart": "", "actualEnd": "",
      "bomVersion": "", "fgCode": "2.01.00.55.0022", "srcMoNo": "",
      "remark": "",
      "createdAt": "2026-10-26 21:05:05",
      "updatedAt": "2026-10-26 21:05:05",
      "issueNo": "", "issueStatus": "", "issueCount": 0
    }]
  }
}
```

字段说明：

| 字段 | 含义 | 备注 |
|---|---|---|
| `moNo` | 工单号（10 位） | 与 WMS 对账用的唯一键 |
| `woType` | 工单类型 | SMT / DIP / 组装 / 包装 / 辅料 |
| `productCode` | 成品/半成品料号 | 就是 MES 的 `product_code` |
| `productName` / `productModel` | 品名 / 机型 | 取 MES 产品档案 |
| `panelCount` | 每版拼板数 | 发料换算用 |
| `planQty` / `outQty` / `ngQty` | 计划 / 已产 / 不良 | 都是**台（PCS）** |
| `status` | 工单状态 | 已排产 / 生产中 / 已完工 / 已关闭 |
| `issueNo` / `issueStatus` / `issueCount` | 已开的领料单号 / 状态 / 张数 | 空表示这张工单还没开领料单 |
| `updatedAt` | 最后更新时间 | **增量同步的时间基准** |

### 3.3 工单详情

```
GET /api/itf/wms/mo/26101001204
```
返回工单头 + `materials[]`（领料明细）+ `issues[]`（领料单），字段同 3.2，另加：

| 字段 | 含义 |
|---|---|
| `materialSource` | 用料来源：`领料单` 或 `BOM V0.8 现算` |
| `bomVersionUsed` | 现算时用的 BOM 版本 |
| `materialCount` | 用料条数 |

### 3.4 领料明细（推荐仓库用这个）

```
GET /api/itf/wms/mo/26101001204/materials
```
```json
{
  "code": 0, "message": "ok", "requestId": "…",
  "data": {
    "moNo": "26101001204",
    "productCode": "2.01.00.55.0022",
    "planQty": 50.0,
    "source": "BOM V2.6 现算",
    "bomVersionUsed": "V2.6",
    "materialCount": 33,
    "materials": [
      {
        "materialCode": "1.02.00.01.0466",
        "materialName": "装配件",
        "spec": "NBT 12V4A美规桌面式电源适配器冷灰色 AI版 Vietnam版",
        "unit": "PCS",
        "qtyPer": 1.0,
        "needQty": 50.0,
        "issueQty": 0.0,
        "openQty": 50.0,
        "mpq": 1,
        "posRef": "",
        "altList": "",
        "isAlt": 0,
        "segment": "组装料",
        "mainCode": "1.02.00.01.0466",
        "source": "bom",
        "suggestIssueQty": 50.0
      }
    ],
    "issues": []
  }
}
```

| 字段 | 含义 |
|---|---|
| `qtyPer` | 单台用量（含损耗前） |
| `needQty` | 本工单需求总量 |
| `issueQty` | 已发料数量（来自 MES 领料单） |
| `openQty` | 缺口 = `needQty - issueQty` |
| `mpq` | 最小包装量 |
| `suggestIssueQty` | **建议发料量**，已按 MPQ 向上取整（仓库按整包发就用这个） |
| `posRef` | 位号（如 `R11`），SMT 上料核对用 |
| `altList` | 替代料清单（`、` 分隔），允许替代时按这个发 |
| `isAlt` | 1 = 本条本身是替代料行 |
| `segment` | 用料段：SMT / 插件 / 组装 / 包装 / 辅料 |
| `source` | `issue` = 来自已开领料单；`bom` = 按 BOM 现算的理论用量 |

> **两个来源为什么要区分**：已开领料单是**现场真实需求**（仓库按它发料即可）；
> 没开领料单时给的是 **BOM 理论用量**（采购提前备料用）。返回里 `source` 已标明，
> 不要混用 —— 理论用量不含替代料实发、也不含返工补料。

### 3.5 待领料工单（仓库轮询首选）

```
GET /api/itf/wms/issue/pending?limit=50
```
只返回「未完工 + 还有用料缺口」的工单，每张带 `materials[]`（只含 `openQty > 0` 的行）。
仓库一个定时任务轮这个接口，就能生成备料任务，不用先拉全部工单再自己算。

## 四、错误码

| HTTP | code | 含义 | 处理建议 |
|---|---|---|---|
| 200 | 0 | 成功 | — |
| 401 | 40101 | 缺少或错误的 `X-Api-Key` | 检查密钥，必要时在 MES 页面重置 |
| 404 | 40404 | 工单不存在 | 先调 `/mo` 确认工单号 |
| 500 | 50001 | MES 内部错误 | 记下 `requestId` 找 MES 维护人查日志 |

**所有响应都带 `requestId`**，报问题时把这个值给 MES，能直接定位到那一次调用（MES 侧有完整日志）。

## 五、联调步骤（10 分钟）

1. 在 MES「订单管理 → 工单下发 WMS」复制 **接口地址** 和 **密钥**
2. `curl` 探活（把密钥换成实际的）：
   ```
   curl -H "X-Api-Key: mes-xxxxxxxx" http://192.168.6.27:8080/api/itf/wms/ping
   ```
   返回 `code: 0` 就通了
3. 拉一次清单：`/mo?page_size=5`，看 `total` 与 `items` 是否有数据
4. 取一张工单的用料：`/mo/{moNo}/materials`
5. 配上定时任务（建议 5 分钟一次）：
   ```
   每轮：GET /mo?updated_since={上次最后一条 updatedAt}&page_size=200
        逐页取完（hasMore=true 就 page+1）
        按 moNo upsert 到本地表
   ```
6. MES 侧「工单下发 WMS」页面的「拉取/推送日志」能看到你们每次调用的时间、来源 IP、条数 —— 联调时对着这个看最快

## 六、注意事项

1. **时间是北京时间（+07:00 越南时间），格式 `YYYY-MM-DD HH:MM:SS`，不带时区后缀**。`updated_since` 三种写法都接受。
2. **增量同步以 `updatedAt` 为准**，不要用 `createdAt` —— 工单会被改（数量、状态、产线）。
3. **分页最大 500**，超过请翻页；`hasMore=false` 表示取完。
4. **数量都是 number（台/PCS），不是字符串**，可直接计算。
5. **工单可能被改状态**（已排产 → 生产中 → 已完工），所以同一 `moNo` 会重复出现，请按 `moNo` upsert。
6. 需要「按 PO 汇总」时用 `/mo?po_no=xxx`，不要自己拼。

---

## 七、MES 侧留痕与权限

- 每次调用都写 `itf_wms_mo_log`（时间 / 动作 / 来源 IP / 条数 / 结果），页面可查最近 200 条
- 密钥可随时重置（旧密钥立即失效）
- 这套接口是**只读**的：WMS 不能通过它改 MES 数据；发料结果目前仍由 MES 领料单记录
