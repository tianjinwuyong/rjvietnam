## 二、职责边界（切换后）

| 事项 | 主责系统 | 说明 |
|---|---|---|
| 来料收货、批次生成、库位 | WMS | 不变 |

## 三、三条硬前置（缺一条就不能按期切）

### 3.1 WMS 侧补丁上线

现状：OA 认领写的 `oa_claimed_by` 在 WMS 里**是死字段**，前端不显示、后端不校验，WMS 检验员照样能提交。

必须：按《IQC接管-WMS侧补丁说明（给WMS维护方）》改造并部署，跑通 6 条验收用例。

**验收判据**：OA 认领后，WMS 提交该批次检验返回 409；OA 释放后恢复正常。

### 3.2 OA 模板库建好（业务工作，非 IT）

现状：`iqc_template` 表为空。切换后检验员点「开始检验」会没有模板，**无法录入**。

需要品质部准备 5 个模板（可按品类，不必按物料编码建 27 个）：

| 品类 | 待检批数 | 模板项目（沿用 WMS 现有骨架） |
|---|---|---|
| 贴片电阻 | 197 | 包装 / 外观 / 尺寸 / 功能 / 环保 / 可靠性 |
| 贴片二极管 | 8 | 同上（按需增减） |
| 贴片IC | 7 | 同上 |
| 贴片热敏电阻 | 4 | 同上 |
| 贴片电容 | 3 | 同上 |

每个项目要填：**规格（spec，尺寸类还需 lsl/usl）、单位、AQL、抽样水平**。填了这些，OA 才能自动推 n / Ac / Re 并逐项判定。

然后在「检验建模」里把 27 个物料编码绑定到对应模板。

**验收判据**：任取一条待检批次点「开始检验」，能看到完整项目清单且 Ac/Re 已自动算出。

### 3.3 人员与权限就位

- OA：给品质角色（`quality`）开 `ipqc:manage` 权限；把检验员账号建好
- WMS：切换日起 IQC 相关角色（`iqc_inspector` 等）**保留查询、禁止作业**——补丁上线后这一步变成双保险，不是必需，但建议做
- 通知：仓库、IQC、品质主管、采购（供应商异常沟通口径变化）

7. **17:30**：当天对账——OA 已审批批次数 vs WMS 已放行批次数，必须相等

## 六、回滚

这套改造的回滚成本很低，因为 **WMS 的补丁只在「OA 认领了该批次」时才生效**：

| 级别 | 操作 | 效果 |
|---|---|---|
| 一级（5 分钟） | OA 侧停止认领，收回 `ipqc:manage` | WMS 立刻恢复原流程（补丁留着不碍事） |
| 二级（10 分钟） | 对已在 OA 认领的批次逐个「释放」 | 这些批次在 WMS 重新可检 |
| 数据 | OA 镜像数据保留 | 不影响 WMS；下次接管可直接复用 |

**不需要**回滚 WMS 的代码，也**不需要**动数据库。

## 七、风险与对策

| 风险 | 后果 | 对策 |
|---|---|---|
| WMS 补丁延期 | 无法硬停用，可能双检 | 切换日顺延；或临时撤掉 WMS 的 `iqc_inspector` 角色（只挡菜单，不挡 API） |
| 模板规格未填完 | 切换当天无法判定 | T-10 设为硬卡点，未完成即延期 |
| 认领后 4 小时未提交 | 锁自动失效，两边都可能动 | 检验员班内完成；OA 有 11 分钟一轮的超时回收任务自动释放并通知 |
| WMS 侧绕过补丁改判 | 库存状态不一致 | OA 对账任务 6 小时一轮，红线差异推送给管理员 |
| OA 提交了但 WMS 落账失败 | 「批了库存没动」 | `retryPendingBackfill` 每 1 分钟重试，10 次后转人工并推送告警 |
| 观察期出现新品类物料 | 没有模板 | 现场在「检验建模」临时建，或走主管人工判定（需填原因） |

## 八、OA 侧已就绪的能力（无需再开发）

| 能力 | 实现 |
|---|---|
| 待检批次同步 | `services/wms-iqc-pull.js`，5 分钟一轮 + 启动 20s 首拉 + 手动 `POST /api/iqc/lots/sync-wms` |
| WMS 已检批次的收口 | 同上，`closeFinishedInWms()`——WMS 已处理的批次在 OA 侧标 `wms_closed`，列表自动隐藏，不积压假待检 |
| 严格度联动 | 按物料查 WMS；`suspended` 时 OA 拒绝认领与开单 |
| 认领互斥 | `claimLot` → WMS `claim` 加锁（补丁后为硬锁）；4 小时 TTL |
| 抽样与判定 | `qc-sampling.js`（GB/T 2828.1）、`qc-judge.js` |
| 结果回写 | `submitRecord` → WMS `/api/oa/iqc/result` |
| 审批后落账 | `approveBackfill` → WMS `/api/oa/iqc/approve` |
| 失败补偿 | `retryPendingBackfill` 1 分钟一轮，10 次转人工 |
| 跨系统对账 | `runReconcile` 6 小时一轮，红线告警 |
| 调用审计 | 所有 OA→WMS 调用写 `iqc_sync_log` |
